# Eclora campaign imagery

Generated with the built-in `image_gen` tool using the user-supplied campaign
and product photographs. The reference images were used for art direction and
packaging details; the compositions are newly generated.

| Page placement | Original PNG | Web image |
| --- | --- | --- |
| About introduction | [Portrait](eclora-about-campaign-v1.png) | [WebP](../../front-end/public/images/eclora-about-campaign-v1.webp) |
| About story | [Product still life](eclora-about-products-v1.png) | [WebP](../../front-end/public/images/eclora-about-products-v1.webp) |
| Contact | [Beauty selection](eclora-contact-campaign-v1.png) | [WebP](../../front-end/public/images/eclora-contact-campaign-v1.webp) |

The exact final prompts and reference roles are recorded in
[campaign-prompts.json](campaign-prompts.json). PNGs preserve the original
generated output. WebP copies use quality 94 without upscaling or creative
changes; Next Image delivers responsive sizes to visitors.

All source product and campaign reference images remain unchanged. The page
images are editable through **Paramètres → Pages du site**.
